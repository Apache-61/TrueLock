# Investigation policy v1

Derived from `docs/investigation/protocol.md`. Loaded at runtime by
`truelock.agent.policy`. Changing this file requires a new version and a
passing eval promotion gate (`data/eval_corpus/eval/` + thresholds).

## Category discipline

```
observed fact ≠ anomaly ≠ hypothesis ≠ lead ≠ evidence ≠ inference ≠ conclusion
```

Never accuse from a detector `risk_score` alone. Never invent amounts,
transactions, counterparties, or evidence IDs.

## Tool selection

1. Prefer the deterministic plan for the lead type.
2. Gemini may propose an override only with **valid** allowlisted tool args.
3. Invalid Gemini args → keep deterministic plan and record an audit note.
4. Never execute a tool with invalid args — `ESCALATE` instead.

## Decisions

| Decision | When |
|---|---|
| `FOLLOW` | New `source_id` / evidence appeared OR hypothesis narrowed |
| `DISCARD` | Empty trail / no productive branch / control-style weak linkage |
| `ESCALATE` | Repeated tool call, repeated result hash, tool error, step/time budget |
| `CONCLUDE` | Minimum evidence for the scheme is present and exposure (if applicable) is computed from sources |

## Minimum evidence by conclusion

- **Round-trip / cycle (`CONCLUDE` + SUBSTANTIATED):** cite root bank movement
  and at least one downstream hop; exposure must equal root amount under
  `ROOT_FLOW` policy when a return is verified.
- **Rapid pass-through (`CONCLUDE` + SUBSTANTIATED):** cite the inbound root
  transfer and the timed outbound hop; exposure equals the root inflow only.
- **Duplicate payment (`CONCLUDE` + SUBSTANTIATED):** cite at least two
  settlements (payments or bank txs) against the same invoice UUID.
- **Control / co-location:** must **not** substantiate; prefer `DISCARD` /
  UNSUBSTANTIATED without inventing fund links.
- **69-B correlation alone:** contextual — discard or leave insufficient;
  never conclude fraud solely from listing status.
- **Unusual timing / concentration alone:** risk signals — discard or leave
  insufficient unless independent money-trail evidence appears.

## Budgets

- Max steps: `MAX_INVESTIGATION_STEPS` (default 10)
- Max seconds: `MAX_INVESTIGATION_SECONDS` (default 30)
- Graph hop depth: default 3, cap 5

## Q&A

Answers must cite retrievable `evidence_refs` from the case. If none exist,
state insufficiency — do not free-reason.
